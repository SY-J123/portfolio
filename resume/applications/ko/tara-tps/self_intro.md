저는 서비스 개선 과정에서 사용자 행동을 측정할 기준이 없어 문제 원인을 특정하기 어려운 상황을 경험한 이후, 사용자 여정을 기반으로 퍼널을 정의하고 이벤트 수집 구조를 설계하는 방식으로 접근해왔습니다. 이를 통해 감에 의존하던 의사결정을 데이터 기반으로 전환하고, 사용자 행동을 분석할 수 있는 환경을 구축하는 데 집중해왔습니다. 또한 이전 회사에서는 이벤트 운영 구조를 분석하며 특정 구간에 손실이 집중되는 문제를 발견하고, 이를 사용자 참여 구조의 문제로 재정의하여 구조를 개선함으로써 참여율을 유지하면서도 손실을 약 50% 감소시킨 경험이 있습니다.

1. 사용자 행동 기반 퍼널 구조 설계 및 데이터 수집 체계 구축

서비스 개선 과정에서 사용자 행동을 측정할 기준이 없어 문제 원인을 특정하기 어려운 한계를 경험했습니다. 당시 의사결정은 직관에 의존하는 경우가 많았고, 실제 사용자 경험 개선으로 이어지지 않는 문제가 반복되고 있었습니다.

이를 해결하기 위해 사용자 여정을 기준으로 핵심 퍼널 단계를 정의하고, 각 단계별 전환과 이탈을 측정할 수 있는 이벤트 수집 구조를 설계했습니다. 단순 이벤트 나열이 아닌, 사용자 행동을 해석할 수 있도록 단계별 목적과 지표를 함께 정의했습니다.

또한 개발자와 협업하여 이벤트 수집 기준과 데이터 구조를 구체화하며, 수집된 데이터가 단순 로그가 아닌 분석 가능한 형태로 활용될 수 있도록 설계했습니다. 이를 통해 사용자 행동을 정량적으로 분석할 수 있는 기반을 마련하고, 데이터 기반 의사결정이 가능한 환경을 구축했습니다.

2. 이벤트 운영 구조 개선을 통한 손실 감소

이벤트 운영 과정에서 특정 구간에 손실이 집중되는 문제가 반복되고 있음을 확인했습니다. 이를 단순 운영 조건의 문제가 아닌 사용자 참여 구조의 문제로 재정의했습니다.

과거 운영 데이터와 사용자 참여 패턴을 분석한 결과, 특정 시간대와 참가 금액 구간에서 손실이 집중된다는 점을 도출했고, 이를 기반으로 참여 방식과 진행 흐름을 재설계했습니다.

그 결과 목표 참여 인원을 유지하면서도 손실을 약 50% 감소시키는 성과를 달성했습니다. 이 경험을 통해 문제를 구조적으로 정의하고, 사용자 행동을 기반으로 해결하는 접근 방식의 효과를 확인할 수 있었습니다.

3. LLM 기반 VOC 분석 구조 설계 프로젝트 (사이드)

기존 VOC 분석은 키워드나 별점 중심으로 이루어져 리뷰의 맥락을 충분히 반영하지 못하거나, 사람이 직접 분류할 경우 시간과 기준 일관성 측면에서 한계가 있었습니다.

이를 해결하기 위해 LLM 기반 자동 분류 구조를 설계했습니다. 사용자 여정, 문제 타입(L1/L2), 감정의 세 가지 축으로 분류 기준을 정의하여 동일한 문제라도 원인에 따라 구분될 수 있도록 했습니다.

또한 분류 결과에 신뢰도 값을 함께 산출하고, 신뢰도가 낮은 경우에는 미분류 상태로 남겨 사람이 직접 검토할 수 있도록 하는 구조를 설계했습니다. 이를 통해 자동화와 정확성 사이의 균형을 확보했습니다.

이러한 구조를 통해 리뷰 데이터를 일관된 기준으로 분석하고, 문제 발생 영역과 우선순위를 도출할 수 있는 환경을 구축했습니다.
