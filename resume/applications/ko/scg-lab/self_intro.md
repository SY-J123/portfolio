# 장시영 자기소개서

## 1. 지원 동기

가스앱이 단순한 도시가스 조회 앱을 넘어, 가스·전기·수도·난방 등 생활 에너지를 하나의 플랫폼에서 관리하는 방향으로 확장하고 있다는 점에 매력을 느꼈습니다. 에너지는 모든 사용자가 매일 필요로 하는 생활 인프라이지만, 실제 사용 경험은 요금 확인, 민원, 납부, 이사, 검침처럼 여러 절차와 조직에 분산되어 있습니다. 이처럼 사용 빈도가 높고 운영 접점이 많은 서비스일수록, 고객의 목소리와 데이터를 기반으로 문제를 구조화하고 우선순위를 정하는 PO의 역할이 중요하다고 생각합니다.

저는 사용자 행동 데이터와 서비스 정책, 운영 프로세스를 함께 보며 문제를 정의하는 기획자입니다. 기능을 많이 만드는 것보다, 사용자가 왜 불편을 겪는지, 어떤 흐름에서 이탈하거나 문의가 발생하는지, 어떤 기준으로 개선 우선순위를 정해야 하는지를 먼저 명확히 하는 방식으로 일해왔습니다. 가스앱의 PO가 고객의 목소리와 데이터를 근거로 우선순위를 결정하고, 출시 이후 운영/개선을 통해 성과를 만들어가는 역할이라는 점에서 제 경험과 지향점이 맞닿아 있다고 판단했습니다.

특히 가스앱은 전국 17개 도시가스사와 약 910만 가구가 사용하는 대규모 생활 플랫폼인 만큼, 하나의 개선이 사용자 경험과 운영 효율에 미치는 영향이 크다고 생각합니다. 저는 VOC와 행동 데이터를 연결해 문제를 정의하고, 정책과 프로세스를 정리해 실행 가능한 요구사항으로 바꾸는 역량을 바탕으로 에스씨지랩의 생활 에너지 플랫폼 확장에 기여하고 싶습니다.

## 2. 주요 경험 및 강점

저의 강점은 고객/사용자 행동에서 출발해 문제를 구조화하고, 개발·디자인·운영 조직이 같은 기준으로 움직일 수 있도록 요구사항과 정책을 정리하는 것입니다.

NSUSLAB Korea에서는 토너먼트 운영 데이터를 분석해 손실이 특정 시간대와 참가비 구간에 집중된다는 점을 발견했습니다. 처음에는 단순한 운영 손실로 보였지만, 데이터를 다시 보니 참여 구조와 보상 조건이 특정 구간에서 비효율을 만들고 있었습니다. 이를 바탕으로 시작 시간과 참가 금액 구조를 조정했고, 목표 참여 인원은 유지하면서 손실을 약 50% 줄였습니다. 이 경험을 통해 문제를 감이나 요청이 아니라 데이터로 정의하고, 비즈니스 목표와 사용자 행동 사이의 균형점을 찾는 방식의 효과를 배웠습니다.

Natris / LULU.AI에서는 사용자 상태와 정책 조건이 복잡하게 얽힌 인증/계정 흐름을 정리했습니다. 소셜 로그인, 비밀번호 재설정, 계정 상태, 예외 케이스가 서로 다르게 처리되면서 사용자 경험과 QA 기준이 흔들릴 수 있는 상황이었습니다. 저는 가입 수단과 사용자 상태를 기준으로 플로우를 재정의하고, 정상/예외 흐름과 정책 판단 기준을 문서화했습니다. 이를 통해 개발·QA·운영이 동일한 기준으로 기능을 검토할 수 있는 구조를 만들었습니다.

또한 개인 프로젝트로 LLM 기반 VOC 분석 구조를 설계했습니다. 앱 리뷰를 단순 키워드나 별점으로 보는 방식은 실제 불편의 맥락을 놓치기 쉽다고 판단했고, 사용자 여정, 문제 유형, 감정을 기준으로 분류 체계를 만들었습니다. 여기에 신뢰도 기반 자동 분류와 수기 검수 구조를 더해, 자동화와 정확성 사이의 균형을 맞췄습니다. 이 경험은 가스앱처럼 민원과 VOC가 서비스 개선의 중요한 입력값이 되는 플랫폼에서, 고객 목소리를 제품 개선 우선순위로 연결하는 데 활용할 수 있다고 생각합니다.

## 3. 협업 방식과 업무 도구 활용

저는 PO의 중요한 역할 중 하나가 각 조직이 같은 문제를 바라보도록 기준을 맞추는 것이라고 생각합니다. 기획자가 요구사항을 일방적으로 전달하는 방식보다, 문제의 배경과 목적, 사용자 흐름, 정책 조건을 함께 정리해야 개발과 디자인 조직이 더 빠르고 정확하게 의사결정할 수 있다고 봅니다.

이를 위해 Figma를 활용해 화면 흐름과 사용자 여정을 시각화하고, PRD에는 기능 목적, 정상 흐름, 예외 케이스, 운영 기준을 함께 정리해왔습니다. 또한 AI 도구를 단순 문서 작성 보조가 아니라, 기획 산출물의 정합성을 검토하고 반복되는 UI 패턴을 빠르게 프로토타이핑하는 방식으로 활용했습니다. 이 워크플로우를 통해 초기 리뷰용 문서 작성 시간을 약 60% 줄였고, 팀의 표준 프로세스로 채택된 경험이 있습니다.

에스씨지랩에서도 고객 VOC, 서비스 지표, 운영 정책, 화면 설계를 분리해서 보지 않고 하나의 제품 개선 흐름으로 연결하겠습니다. 특히 가스앱/FMS처럼 사용성과 운영 효율이 함께 중요한 서비스에서는, 데이터 분석과 현업 커뮤니케이션을 바탕으로 실질적인 개선안을 만드는 PO가 되겠습니다.

## 4. 입사 후 계획

입사 후에는 먼저 가스앱의 핵심 사용자 여정과 운영 구조를 빠르게 파악하겠습니다. 요금 조회, 납부, 민원, 이사, 검침 등 사용자가 반복적으로 접하는 흐름에서 어떤 지표와 VOC가 발생하는지 확인하고, 현재 제품 목표와 운영 정책이 어떻게 연결되어 있는지 이해하겠습니다.

이후에는 VOC와 행동 데이터를 함께 분석해 개선 우선순위를 정하는 데 기여하고 싶습니다. 단순히 문의가 많은 기능을 고치는 것이 아니라, 사용자 불편이 어느 단계에서 발생하고 어떤 운영 비용이나 이탈로 이어지는지 구조적으로 정의하겠습니다. 이를 바탕으로 개발·디자인·사업 조직과 협업해 문제를 요구사항으로 전환하고, 출시 이후에는 지표와 VOC 변화를 확인하며 개선을 반복하겠습니다.

장기적으로는 가스앱이 생활 에너지 플랫폼으로 확장되는 과정에서, 사용자 경험과 운영 프로세스, 데이터 기반 의사결정을 연결하는 PO로 성장하고 싶습니다. 에너지라는 생활 인프라를 더 쉽고 편리하게 만드는 제품을 통해, 고객에게는 명확한 편의성을, 회사에는 지속 가능한 서비스 성과를 만드는 데 기여하겠습니다.
